# simple-calculator
A simple calculator built with HTML, CSS, and JavaScript

## Tic Tac Toe

Open `tic-tac-toe/index.html` in a browser. Play against a bot, a friend on the same device, or a friend on another device (online). The bot has three difficulties:

- **Easy** – plays mostly at random
- **Medium** – takes wins and usually blocks yours, but makes mistakes
- **Impossible** – perfect minimax play; the best you can get is a draw

Includes a scoreboard, choice of X or O vs the bot, custom player names, and a light/dark theme.

### Online play

Choose **Online**, tap **Create online game** and share the invite link (or the 5-character code). The two devices connect directly to each other using [PeerJS](https://peerjs.com/), which uses its free public server only to introduce them. Online play needs the page served over HTTPS, for example from GitHub Pages, and works in Safari on iPhone. Use Share → Add to Home Screen to get an app icon.
