# simple-calculator
A simple calculator built with HTML, CSS, and JavaScript

## Tic Tac Toe

Open `tic-tac-toe/index.html` in a browser. Play against a friend on the same device, or against a bot with three difficulties:

- **Easy** – plays mostly at random
- **Medium** – takes wins and usually blocks yours, but makes mistakes
- **Impossible** – perfect minimax play; the best you can get is a draw

Includes a scoreboard, choice of X or O vs the bot, custom player names, and a light/dark theme.
